# Changelog

## 0.2.0rc1 — migration review candidate

This breaking candidate establishes canonical units, immutable named weighted
catalogs with independent weight factors, staged population execution and source
provenance. Distribution name is `sashimi-itamae`; import name remains `itamae`.

Shared mechanisms now include explicit cosmology adapters with isolated global
state, NFW inverse/profile contracts, deterministic quadrature and realizations,
controlled ODE execution, power/variance composition and content-addressed caches.
Invalid input, mismatched metadata and cache corruption fail explicitly.

Physics, calibrations, transfer functions and model defaults remain owned by each
SASHIMI variant. Migration preparation includes analytic, independent integration,
backend, reference and artifact checks; it is not physical calibration.

No release upload or main integration has been performed for this candidate.
