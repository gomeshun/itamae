# Colossus とモデルをそろえた SASHIMI-C の EPS 計算

物理質量 $10^{-6}$～$10^{12}\,M_\odot$ の73点で、分散 $S(M)=\sigma^2(M,0)$ と Colossus 既定値の最大相対差は **3.3725% → 0.02470%** になった。両実装で積分の上下限と振幅の決め方もそろえると **0.00000470%**。これらは同じ入力で計算した二つの数値の差であり、数学的な誤差上限は別途区間評価で求めた。[比較 PDF](matched-comparison.pdf) · [数値比較 CSV](matched-samples.csv) · [区間端点 CSV](enclosures.csv)

系列の値を $x$、基準値を $b$ とおく。各基準の上の段は $100|x/b-1|$ [%] を対数目盛で示す。厳密に一致する標本は各対数軸に付けたゼロ専用欄に表示する。同じ基準の下の段は $100(x/b-1)$ [%] を線形目盛で示し、差の向きとゼロを読み取れる。負の微分にも元の符号で $x/b$ を計算する。同じ量の二つの対数パネルには共通の縦軸範囲を使い、二つの線形パネルの範囲もそろえた。

CSV の `legacy_reference_exact` と `matched_reference_exact` は分母の正確な有理数を、`rel_{key}_vs_legacy` と `rel_{key}_vs_matched` は各系列の $x/b-1$ を符号付きで記録する。例えば CSV の −0.001 は、図の対数パネルで 0.1%、線形パネルで −0.1% に対応する。[数値比較 CSV](matched-samples.csv)

- 旧処方の基準値（`legacy`）には、全量で前回の Lean 証明区間の有理数端点から計算した中点 $(L+U)/2$ を使う。[前回の結果](../eps-plots/README.md)
- 整合後の基準値（`matched`）のうち $H,D,dD/dz,\delta_c$ は、対応する証明区間の有理数中点を使う。$H$ は両処方で共通なので、二つの相対差が一致する。$\sigma,S,dS/dM$ は Lean の binary64 数値積分の出力を使う。$F,M_{200}$、質量変化率はその分散を入力として Lean で下流の式を区間評価し、中点を binary64 に丸めた値を使う。相対差の分母には保存した各 binary64 値を正確な有理数として読み込む。これらの値が960セルの主計算で得た証明区間に入ることを各標本で確認した。真のモデル値 $y$ に対して、表示値 $x$ の絶対誤差は $|x-y|\le\max(|x-L|,|U-x|)$ で抑えられる。[区間端点 CSV](enclosures.csv) · [Lean の数値積分](lean.json)

[診断 PDF](matched-diagnostics.pdf) は、[960セルと7,680セルの積分・EPS区間](matched-enclosures.png)、[区間から得た数値誤差上限と実装間の差](matched-precision.png)、[伝達関数・膨張率・障壁の検査精度](matched-transfer-growth.png) の3ページ。EH98 の $T(k)$ には前回の SASHIMI-C の計算で対応する基準値がなく、診断図には区間と実装間の比較を載せた。`matched_lo_exact` と `matched_hi_exact` に整合後の厳密な有理数端点、`enclosure_status` に各行の検査範囲を記録した。標本間の線は描画用である。

## 共通の物理モデルと単位

- Colossus **1.4.0** の `modelEisenstein98` と同じバリオン音響振動を含む CDM＋バリオン伝達関数を実装した。背景は空間的に平坦な物質＋Λ。$h=0.674,\ \Omega_m=0.315,\ \Omega_b=0.049,\ n_s=0.965,\ \sigma_8=0.811$。$T_{\rm CMB}=2.7255\,\mathrm K$ は伝達関数の入力で、低赤方偏移の背景と成長では放射を無視した。今回の図は線形 CDM スペクトルを使う。Colossus が CAMB と照合したと記載する約 $100\,h/\mathrm{Mpc}$ を超える領域では、このフィットの外挿が微小質量の予測に入る。証明の範囲は指定された実数式の評価である。[Eisenstein & Hu (1998)](https://arxiv.org/abs/astro-ph/9709112) · [Colossus のパワースペクトル](https://bdiemer.bitbucket.io/colossus/cosmology_power_spectrum.html) · [Lean の伝達関数](../../src/SashimiEisensteinHu.lean)
- 入力質量 $M$ は物理太陽質量。Colossus には $hM$ を渡す。窓半径 $R=(3hM/[4\pi\Omega_m\rho_{\rm crit,0}])^{1/3}$ は Mpc/h、$k$ は h/Mpc。ここで臨界密度の数値は Colossus と同じ $277536627245.708$。伝達関数の内部では $hk$ を使う。窓は $W(x)=3(\sin x-x\cos x)/x^3,\ W(0)=1$。[参照実装と単位換算](../../scripts/eps_eh_reference.py)
- $P(k)=A k^{n_s}T(k)^2$。$J(R)=\int k^{2+n_s}T(k)^2W(kR)^2\,dk$ として、$S(M)=\sigma_8^2J(R)/J(8)$ を使う。分子と基準半径の積分を独立に囲み、共通の $2\pi^2$ を消去する。質量微分は同じ窓を積分内で解析微分したもの。赤方偏移の成長は平坦物質＋Λの Heath 解 $D(a)\propto E(a)\int_0^a da'/(a'E(a'))^3$ を $D(z=0)=1$ で規格化した。[分散の実装](../../src/SashimiEhVariance.lean) · [微分の成立条件](../../src/SashimiEhContinuity.lean) · [成長解](../../src/SashimiHeath.lean)
- 前回と共通の物理質量と赤方偏移 $z=0,0.25,\ldots,7$ を使った。Yang の条件付き密度 $F$ は親 $10^{12}M_\odot,z=0$、子 $M,z=1$ の72組。各実装の $S$ と障壁 $1.686/D$ を同一の式に代入した。ホスト量も同じ SASHIMI-C の質量履歴とビリアル質量への換算に、各方式の分散と成長率を入力した。Astropy の成長比較は `FlatLambdaCDM` の $E(a)$ と SciPy 積分から得た。[前回の実装・参照データ](../eps-plots/README.md) · [ホストと EPS の入力](downstream.json)

## 形式化した物理仮定

- **背景の方程式。** Physlib の `FriedmannSolution` は、指定した時間区間で第1・第2 Friedmann 方程式を満たす解である。Lean の接続定理はその解、平坦性、基準時刻で $H_0>0$、評価時刻で $H\ge0$、物質密度の $a^{-3}$ 則を仮定する。放射を空の流体として、閉包関係から $\Omega_\Lambda=1-\Omega_m$、赤方偏移の関係から $H(z)=H_0 E((1+z)^{-1})$ を導く。一般の放射・曲率を含む接続では、物質と放射の分解、$a^{-3},a^{-4}$ 則、基準時刻の密度・赤方偏移と数値入力との一致を定理の引数に取る。[Physlib の解の定義](https://github.com/leanprover-community/physlib/blob/db96e88549c3ed2b1211fe34cd751f30847e5386/Physlib/Cosmology/FLRW/Basic.lean#L438) · [平坦模型への接続](../../src/HzFriedmann.lean) · [放射・曲率を含む版](../../src/SashimiBackground.lean)
- **スペクトルとハロー。** 今回は EH98 の伝達関数、Heath の成長則、球対称崩壊の障壁 $1.686/D$、Yang の二時刻の条件付き密度、ホストの質量履歴・ビリアル換算の処方を選んだ。証明は指定した式とパラメータから分散、微分、区間を導く。実在するハロー集団に対する適合精度には、シミュレーションや観測による較正とその誤差が必要である。別の WDM モジュールではこの違いを `WdmFitAgreement` で表す。適用領域で真のパワーとフィットの差が $e(k)$ 以下と仮定すると、フィットの計算区間 $[L,U]$ から物理パワーの区間 $[L-e(k),U+e(k)]$ を導ける。[EPS の実数仕様](../../src/SashimiEpsKernel.lean) · [ハローの経験式](../../src/SashimiHalo.lean) · [WDM の誤差仮定](../../src/SashimiWdm.lean)
- **有効自由度の例。** 独立した熱史モジュールは Saikawa–Shirai の解析フィットを評価する。1 GeV で $g_{*\rho}^{\rm fit}\in[69.7437,69.7438]$、$g_{*s}^{\rm fit}\in[68.7715,68.7716]$ を有理数の上下限で証明した。物理的な真値を扱う定理は、原表の隣接点での平均と絶対誤差を温度で線形補間した帯が、そのセル全域で両関数を覆うという仮定 `SaikawaShiraiDoF` を取る。この仮定の下でフィットと真値の差を、表の絶対誤差を補間した値と、補間した平均とフィットの差の絶対値との和で抑え、放射密度・エントロピー密度へ伝播する。二時刻のスケール因子比を導くには共動エントロピー保存も仮定する。今回の EPS 図の計算はこれらの熱的自由度を入力に使っていない。[有効自由度の定理](../../src/SashimiThermal.lean) · [原表、補間と不確かさ](../../THERMAL.md)

- **既定**は実際の Colossus の補間テーブルを使った結果。**補間なし**は公開実装の直接積分で、半径ごとに積分範囲を自動選択する。既定の相対積分許容誤差は 0.003。質量微分は、そのままの許容誤差では差分が不安定になるため、同じ振幅を保持し許容誤差を $2\times10^{-8}$ にして積分範囲を局所的に固定し、Richardson 外挿を用いた。緩い設定での差分も JSON に残した。[Colossus の設定、積分範囲、四捨五入前の値](colossus.json)
- **同一帯域**では $k\in[10^{-8},10^{10}]\,h/\mathrm{Mpc}$ で Colossus の関数を独立に再積分し、$R=8\,\mathrm{Mpc}/h$ も同じ帯域で再規格化した。Lean の振幅は $A=2891239.45931$、同一帯域の Colossus 積分は $2891239.46171$、Colossus 既定の振幅は $2891272.85222$。Colossus のスプラインで評価した基準半径は $\sigma(8)=0.8113660$。小さい $kR$ で Lean は窓の級数を評価し、Colossus は $kR<10^{-3}$ で窓を 1 とする。微分の残差には有限差分と積分許容誤差も寄与しうる。[Lean の数値・収束診断](lean.json) · [最大差の標本位置](matched-summary.json)
- Lean の中心線には binary64、対数波数上の合成 Simpson 則、補償和を使用した。1 decade あたり 2,048 → 8,192 パネルに細分したときの最大相対変化は $S$ が $2.44\times10^{-12}$、$dS/dM$ が $5.53\times10^{-10}$。独立した帯域拡張も記録した。4回の数値積分とホスト用の追加質量を含む所要時間は約79秒。この収束診断と実装間の一致桁数を、証明付き誤差として使うことはできない。[実行設定と標本ごとの変化](lean.json)

## 包含区間は何を保証するか

区間は固定した宇宙論パラメータと物理的な処方の下での実数値を囲む。ネイティブ計算の丸め誤差、ライブラリ間の差、物理モデルの不確かさはそれぞれ意味が異なる。

- **伝達関数。** 同じ Lean 定義を実数式、ネイティブ Float、FloatLib の区間式として評価する。10個の指定波数の $T(k)$ の実数値をカーネルで囲んだ。相対区間幅の最大は $1.22\times10^{-11}$。この10点でネイティブ値は Colossus とビット単位で一致した。一方、10点中8点では両者に共通の丸め値が実数値の狭い区間の外にある。図の連続線用に同じ binary64 波数498点でも独立に比較し、487点でビット一致、最大相対差は $2.23\times10^{-16}$ 未満だった。[厳密な端点](transfer.json) · [検査可能な証明](transfer.lean) · [ネイティブ曲線](transfer-samples.json)
- **成長と障壁。** 実数の Heath 積分を変数変換し、多項式と解析的な剰余上限を使った。$D, dD/dz, 1.686/D$ の29組の区間をカーネル検査した。絶対区間幅の最大は順に $2.54\times10^{-14},4.22\times10^{-14},3.08\times10^{-13}$。背景の $H(z)$ は共通で、Physlib の規格化膨張率および Friedmann 解と前回の証明で接続している。バリオン伝達関数は EH98 の経験式を物理的入力として採用した。[成長の証明書](growth.lean) · [背景の比較](../eps-plots/background.png) · [Friedmann 方程式との接続](../../src/HzFriedmann.lean)
- **分散。** 各波数セル全体で解析的伝達関数と窓を囲む。$L=10^{-8},\ K=10^{10}$ の外は $k>0$ で $|T|\le3$、$k\ge K$ で $|T|\le10^{-9}/k$ を証明し、分子・分母それぞれの切り捨てを外向きに加えた。積分全体の $S$ と $\sqrt S$ に対する上下限になる。7,680セルで得た $S$ の区間全幅は数値積分値の18.2～23.5%。同じ点で2つの実装が示す数値差より、積分の保証幅は広い。[全波数の定理](../../src/SashimiEhFullGrid.lean) · [帯域外の評価](../../src/SashimiVarianceTails.lean) · [960セルの厳密な端点](full.json) · [7,680セルの端点](full-fine.json)
- **分散の質量微分。** 正の物理質量について窓の微分を積分内に入れられることを、全波数に共通する可積分な上界で証明した。有限帯域の符号付き積分を計算し、両端の寄与と規格化分母の誤差を外向きに加える。$10^{12}M_\odot$ では中心値 $-1.42793788\times10^{-12}\,M_\odot^{-1}$、7,680セルの全波数区間は $[-1.88644,-1.13947]\times10^{-12}\,M_\odot^{-1}$。このモデルで標本ごとに微分の符号まで確認できる。[微分と積分の交換](../../src/SashimiEhFullCalculus.lean) · [全波数の誤差定理](../../src/SashimiEhFullDerivative.lean) · [ホスト質量での具体的な微分証明](proofs/full-slopes/FullDerivative72_72.lean) · [細分時の端点](derivative-full-fine.json)
- **ホスト質量・質量変化率。** 形成赤方偏移から $q$ を決める Correa の式と $M_0/q$ を実数式として評価し、そのラグランジュ半径を同じ積分セルで囲んだ。$S(M_0/q)-S(M_0)$ と Heath 解の $D'(0)$ を、SASHIMI-C の質量履歴と質量変化率に伝播した。質量変化率には SASHIMI-C のビリアル質量フィットがかかる。ホストの図の縦線はこうして得た上下限である。[ホストの実数仕様](../../src/SashimiEhHost.lean) · [ホストの厳密な端点](host-bounds.json)
- **条件付き密度。** $F=\Delta\delta\exp[-\Delta\delta^2/(2\Delta S)]/(\sqrt{2\pi}\,\Delta S^{3/2})$。親子と基準半径の積分の上下限を使い、共通の規格化を保存して $\Delta S$ を評価した。親子の $S$ を独立に規格化してから差し引く方法より、依存する入力をそろえて計算する方が区間を狭くできる。とくに親に近い子質量で効く。[EPS の証明](../../src/SashimiEhYang.lean) · [条件付き密度の区間](kernel-bounds.json)

代表的な値は以下のとおり。角括弧の小数端点は7,680セルの出力を外向きに丸めた。CSV と JSON は厳密な有理数端点を持つ。

| 物理質量 [太陽質量] | Lean の $S$ | Colossus 既定の $S$ | $S$ の全波数区間 | $\sigma$ の全波数区間 |
|---:|---:|---:|---:|---:|
| $10^{-6}$ | 613.28103778 | 613.30454636 | [555.7258, 667.2773] | [23.5738, 25.8318] |
| $10^{12}$ | 5.01160011 | 5.01201025 | [4.4722, 5.6469] | [2.1147, 2.3764] |

親に最も近い子 $M=5.6234132519\times10^{11}M_\odot$ では、数値密度 $F$ は Lean が 0.26973089、Colossus 入力が 0.26981230。親子の分散差を同じ波数セル上で囲むと、960セルでも正値性を確定できる。$F$ の指数と分母が同じ $\Delta S$ に依存するため、幅の広い入力区間を分割してから各結果を合わせた。7,680セルの区間は [0.15109, 0.45935] となった。[細分時の EPS 区間](kernel-bounds-fine.json)

## 実行時間

同じ74質量（格子73点とホスト用の追加質量）で分散と質量微分を取得した。Lean で147,456パネルの積分を1回計算すると **63.13秒**、Lake の起動を含めると **71.17秒**（プロセス CPU 時間33.50秒）。Colossus の既定スプラインではテーブルの初期構築が **0.110秒**、構築済みテーブルから74点を配列で取得する時間は **60.3マイクロ秒**（100回の中央値）。同じ格子の再計算結果は両方式とも保存した148数値と一致した。これらは数値予測の時間である。[ベンチマークの設定と測定値](benchmark.json)

解析式の区間評価は960セルで22.51秒、7,680セルで198.02秒。960セルのスペクトル、基準半径、ホストの分散をカーネルで一から再検査する時間は、依存ライブラリのビルド後で173.64秒だった。残りの質量ではこのスペクトルと基準半径の証明を共有する。計測機は AMD EPYC 9V74 の4 CPU相当の割当で、複数の検証ジョブが同時に動いていた。[共有スペクトルの検査記録](kernel-host.json) · [ホスト1点を全波数へ拡張する証明](full-mass-72.lean) · [質量ごとの検査時間](mass-replay.json)

## 検査と信頼境界

主計算の465個の包含区間がカーネル検査を通過した。内訳は背景・成長・障壁116個、分散・標準偏差・質量微分219個、条件付き密度72個、ホスト質量と質量変化率58個。伝達関数の10点と追加の前駆ハローはこの個数の外で検査した。[実行ログ](verification.txt) · [全波数での分散と平方根の証明](full-closed.lean) · [全72組の条件付き密度の証明](kernel-bounds-closed.lean)

960セルの主計算では、カーネルが各セル全域の伝達関数、窓、積分和、物理質量からの半径、規格化を順に検査する。Python は候補の端点と証明を生成する。例えば、ホスト分散の下限を 8 に改変した証明書、質量微分を区間 [0,0] とした証明書はいずれも拒否された。公理の監査対象にはプログラムが生成した個別の定理も含めた。標準の `propext`、`Classical.choice`、`Quot.sound` を許容した。これらは Lean の基礎公理であり、宇宙論の仮定は定理の引数または対象モデルの定義に現れる。[監査の実装](../../src/HzAudit.lean) · [FloatLib の信頼境界](https://github.com/lean-dojo/FloatLib/blob/d24844f039320a024c7548f992920562d9a71a60/TRUST.md)

7,680セルでは、正しさを証明した評価器で連続な実数モデルを区間評価した。セルごとの具体的な積分和には Lean 実行系を使い、そこから上下限への伝播はカーネルで再検査した。細分時の区間、ネイティブの中心線、Colossus や Astropy の数値比較はこの信頼範囲に応じて記録している。EH98 やハローの経験式に含まれる物理的なモデル誤差は別に評価する必要がある。
